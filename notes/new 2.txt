why java?
	1. platform independent (write once run anywhere!)
	2. simple & robust
	3. secure
	4. Automatic memory management	-- GC: free the memory
	5. Multi thread support
	6. Object-Oriented support		-- Encapsulation, Inheritance, Polymorphism, Abstraction
	7. I/O support
	8. Networking support -- TCP/UDP programming
	9. Functional programming support
