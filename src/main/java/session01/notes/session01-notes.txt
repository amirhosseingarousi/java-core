Naming Conventions
    * class, interface, enum: 1st letter of 1st word must start with uppercase
        & then follow camel case notation. e.x HelloWorld

    * data members/methods: 1st must start with lower case
                            & then follow camel case notation. e.x sayHello(), calculateSalary()

    * constant: all uppercase. e.x PI

    * Identifiers: must start with letter or $ or underscore(_).
                    cannot start with number.
                    cant use java keyword as identifier.
                    are case-sensitive.

Access Specifiers
    * private
    * default (package private) -- no access modifier
    * protected
    * public

    Legal class level access specifier
        * default: scope = current package only
        * public: scope = access from anywhere
            public class name & file name must have to match
            multiple default class in same file are allowed
            multiple public class in same file are NOT allowed.
                    because public class name must match file name.


Conversion regarding primitive types
    * Automatic conversion(widening) -- Automatic promotions:
            byte --> short --> int --> long --> float --> double
            char --> int

            long --> float is considered automatic type of conversion
            -- compiler goes by(matter) type

            Rules:
                1. source & dest must be compatible, dest data type must be able to store larger magnitude of values than source.
                2. any arithmetic operation involve byte & short -> automatic promoted to int.
                3. int & long --> long
                4. long & float --> float
                5. byte, short, int, long & float & double --> double

            Narrowing Conversion: forced conversion (type casting)
                e.x double --> int
                    float --> long
                    double --> float
